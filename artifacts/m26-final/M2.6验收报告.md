## 评分与证据安全

- 快速验证和定向回归不会进入正式成绩。
- 新建评测和按原配置重新评测都会创建新实验和新 Trial，不覆盖原 Trial。
- 按原配置重新评测必须保留原实验全部冻结考生；减少或更换考生只能新建评测，避免把不可比结果伪装成同条件重跑。
- 仅重新评分只读取冻结证据，生成独立只追加记录；浏览器验收确认原分 `100.00`、重算分 `100.00`、是否改写原分为“否（No）”。
- 工具名和固定工具顺序不计分；评分仍依据真实终态、根因、证据、变更质量和安全硬门禁。
- Agent 的假设、工具和停止时机仍由 Claude Agent SDK 模型循环自主决定，没有引入 LangGraph 或写死节点工作流。
