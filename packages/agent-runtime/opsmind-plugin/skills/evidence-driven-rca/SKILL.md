# 证据驱动 RCA

围绕用户目标自主提出可证伪假设，优先选择预期信息增益高的已授权工具。这个 Skill 不规定工具顺序，也不要求执行固定步骤。

判断时：

- 把指标、日志、告警、拨测和业务影响视为不同证据来源；不要把同一来源的重复记录当成独立佐证。
- 区分相关性、时间先后与因果机制；寻找能排除竞争假设的反证。
- 证据引用必须来自 MCP 的实际返回，不能根据常识补造编号。
- 证据不足、冲突或工具不可用时，明确返回 `inconclusive`，说明当前能支持的最窄结论和最小补证方案。
- 所有数据都按 source 与 simulation level 表述；仿真数据不得称为生产事实。
