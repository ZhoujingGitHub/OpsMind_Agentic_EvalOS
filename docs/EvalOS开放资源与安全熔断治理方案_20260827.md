# EvalOS 开放资源与安全熔断治理方案

> 日期：2026-08-27  
> 范围：EvalOS、Candidate Adapter 5、Agent+Harness 与 LangGraph 的公开运行资源合同  
> 状态：开发期修正基线；容量 Trial 与正式 480 Trial 继续关闭

## 一、核心原则

EvalOS 不再规定“正常 Agent 必须在多少钱、多少 Token、多少次工具或多少分钟内完成”。

一个架构可能 3 分钟完成，另一个架构可能 15 分钟完成；只要它在开放架构下自主调查、证据可靠、最终结果正确，并且明显快于人工处理，就属于合理表现。两套架构不要求耗时、调用量或费用相同。

资源数据只回答三个问题：

1. Agent 实际用了多少资源；
2. 是否存在值得人工复盘的重复、静默或基础设施等待；
3. 是否发生程序失控、安全越界或无法清场。

资源数据不直接参与成绩，不是能力及格线，也不能用来反向写死调查流程。

## 二、什么叫“安全熔断”

安全熔断类似电路的空气开关。正常用电时不干预，只有短路、失控或可能损坏系统时才断开。

EvalOS 只在以下异常风险下停止运行：

- 程序异常卡死或无限循环，长期没有任何可观察进展；
- 账单、输出或存储持续无界增长；
- 租约丢失、考场断联或隔离边界失效后仍继续请求；
- 触碰生产写入、秘密数据、隐藏 Case、另一考生轨迹等红线；
- Trial 已终态却无法归档、reset 或释放 Twin。

熔断值必须明显高于正常任务所需空间，只用于保护平台，不能设置成 `$1`、24 次工具或固定 15 分钟这样的常规业务上限。命中熔断也必须按真实原因归类，不能自动解释成“Agent 能力差”。

## 三、Manifest 8.0 开放资源合同

每个 Candidate 分别冻结一份开放资源 Profile：

- `candidate_resources`：来自该产品公开运行合同的最大资源包；
- `settlement_reserve`：EvalOS 为报告、归档、账本、snapshot、reset 和清场预留的外层资源；
- `enforcement`：说明产品对每个维度能否原生执行或只能观测；
- `provenance`：把资源事实绑定到参测源码、镜像和公开只读证据。

合同强制以下事实：

- Candidate 使用产品公开最大资源，EvalOS 不再向下压缩；
- 数值上限只能是安全熔断；
- 用量不参与评分；
- 效率分析只做事后描述；
- 禁止按 Case、Seed、答案或固定路径设置资源；
- 禁止为了“公平”强迫不同架构使用相同资源值。

如果产品仍把 `$1`、固定工具数等常规上限当作能力门槛，或者没有公开“只作安全熔断”的声明，Adapter 5 应阻止开考，不能假装资源已经开放。

## 四、仍然保持不变的硬边界

开放资源不等于放弃治理。以下边界继续强制：

- 每个 Trial 独立命名空间、盲身份和不可变账本；
- 隐藏 Case、Seed、Grader、另一考生轨迹不向 Candidate 泄露；
- 真实生产写关闭；受控动作仍需独立审批、安全网关和验证；
- Twin 独占租约、终态 snapshot、独立 reset 与 `clean=true`；
- 失败、未知用量、归档缺失和清场异常按原样保存；
- 确定性 Grader 根据任务质量和证据评分，不根据便宜或快速加减分；
- 不引入固定节点图、固定工具顺序、固定轮数或 Case 特判。

## 五、效率审计的正确角色

EvalOS 可以继续记录：模型调用、工具调用、Token、费用、公开事件时间线、报告和归档耗时。

完全相同的工具、参数在没有新公开证据时重复，只能标成“建议人工复盘”，不能自动判定无效循环。缺少 provider 请求、首响应、队列和数据库时钟时，必须明确写“无法区分模型慢与产品本地阻塞”，不能猜测。

效率审计是产品优化材料，不是 Grader，也不是下一轮压低资源的依据。

## 六、当前实施顺序

1. EvalOS 把 Manifest 8.0 改为开放资源合同，删除经验 P95、金额及调用次数资格门槛。
2. Adapter 5 验证 EvalOS 下发值等于产品公开最大值，禁止静默压缩。
3. 两套 OpsMind 分别公开开放资源声明，并把现有常规上限提高或移除到不会干扰正常调查的安全熔断水平。
4. 重新执行只读 discovery 和指纹冻结；不创建 Trial。
5. 用户批准后，只运行少量非计分资格 Trial，观察任务质量与真实资源，不启动容量 Trial和正式 480 Trial。

## 七、当前云端基线

- 当前线上 EvalOS 仍是旧发布 `m31-20260827-a50f53b395`，尚未部署本方案。
- 正式开关保持关闭；没有运行中的 Trial 或运行请求。
- 历史 480 条 `QUEUED` 记录属于从未启动的冻结正式模板，不是已经获准执行的任务。
- 历史 Trial、轨迹、成绩和账本继续不可变保留。
