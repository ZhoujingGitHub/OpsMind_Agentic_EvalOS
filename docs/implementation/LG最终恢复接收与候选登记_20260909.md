## 行为

LG 1.3 公开合同将当前动作与历史尝试分开。接收器保留所有动作事件；最终恢复必须绑定当前动作、提案摘要、执行回执和独立验证报告，验证时间不得早于执行完成，验证后不得再有写动作。先前执行动作必须已安全关闭并有重新调查事件，未知写入或未解决升级不得算恢复。

例如第一次执行失败且没有改变环境，独立验证未恢复，关闭旧动作后继续调查；第二次提案重新审批、执行成功、独立验证有效，最终可以记为已恢复，并说明“第1次修复未恢复；第2次修复成功，独立验证有效”。第一次失败仍保留在事件、尝试历史和账本中。旧公开合同保持原解释，不重算历史。

审批请求同时绑定动作 ID 和提案摘要，拒绝当前动作引用与待审批提案不一致。评分器、最小变更规则和安全门槛未改；结果接收通过不等于场景验收通过。
