# 开发期 MVP 任务1：最小外围合同与本地失败测试

- 日期：2026-08-31
- 结论：**任务1通过，可以进入任务2。**
- 范围：只增加外围合同和本地验证，没有连接5G实验室，没有修改两套 OpsMind、EvalOS 或实验室的核心调查与评测逻辑。

## 这次固定了什么

1. 只承认三种模式：LangGraph 直连、Agent+Harness 直连、EvalOS 单 Trial 评测。
2. 整个物理5G实验室只有一份租约，机器重启或租约异常后必须隔离并明确复位。
3. 两套候选产品各用独立签名密钥向一个 HTTPS 入口短期报到；EvalOS 只保存在内存，重启后旧 ready 失效。
4. readiness 分两次：准备实验室前只做未绑定预检；准备完成后、模型启动前核对精确 Trial 和租约。
5. 每个产品只保留 current/previous；应用回滚不能回滚数据库，也不能碰另一产品。
6. 部署账号只有本产品 `status`、`apply`、`rollback` 三种固定命令，没有通用 shell 或 Docker 权限。
7. Manifest 8.0 继续给每套产品自己的公开最大资源；Token、时长、调用量和费用只记录、不评分。AI Judges 和 AI 调查分析能力继续保留。

完整人话合同见 [`../contracts/开发期MVP外围合同_v1.0_20260831.md`](../contracts/开发期MVP外围合同_v1.0_20260831.md)。

## 验证结果

- 外围合同专项测试：12项全部通过。
- EvalOS 全量测试：156项全部通过。
- 已验证会阻断：争抢实验室、开机身份改变、过期租约、伪造签名、错用另一产品密钥、重放、过期报到、EvalOS 重启沿用旧 ready、Trial/租约/数据库不匹配、通用 Docker/shell 命令、应用回滚碰数据库或另一产品。
- 已验证开放资源评分：相同任务结果即使 Token、耗时、工具次数和费用不同，Grader 5.2 正式分数不变。

第一次全量测试因这个新工作树尚未安装仓库已经锁定的 Agent Runtime 开发依赖，有6个测试未能启动。按子目录 lockfile 安装原有固定版本后重跑，156项全部通过；没有改变依赖版本或评测能力。

## 没有做什么

- 没有把合同写成第二个数据库或第二套发布平台。
- 没有新建 Redis、注册中心、常驻租约服务或 Candidate 中继服务。
- 没有让外围规定 Agent 的调查步骤、工具顺序或停止时间。
- 没有删除旧入口；旧入口只会在任务5新路径验收后一次性删除。
