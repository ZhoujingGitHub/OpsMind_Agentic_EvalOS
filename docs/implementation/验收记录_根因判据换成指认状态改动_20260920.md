## 第四张图：门（能不能通过）怎么变的

先说结论：**通过与否交给「结果」，说得对不对只算分。**

打个比方。以前是这样：**医生说病名说错了，哪怕病人被治好了，也算医疗事故。**
现在改成：**能动手治的病，看病人好没好；不让动手的病（只许诊断），才看说得对不对。**

```
【能动手修的题】（今天四道里有三道是）
     门 = 只改了一处  +  实验室独立复测业务从断到通
     ────────────────────────────────────────────
     诊断说得多准？只影响那 40 分，不影响通过。

【不让动手的题】（只诊断、安全停止）
     门 = 指认对了那处改动
     ────────────────────────────────────────────
     没有"治好了"这个结果可依，那就只能看说得准不准。
```

**为什么这条最重要**：今天那四道里，`trial_a65c8f5e`（公开基线）和
`trial_114dc659`（恢复回归）这两次，**真的执行了一次最小处置，
实验室独立复测业务已经恢复**，失败的硬门**只有根因那两道**。

换句话说——**把编号那一关拿掉，这两次本来就是满盘通过的。**

这件事我已经钉成一条测试：一份**完全没有指认字段**的答卷（今天那次运行就是这样，
因为这个字段是这一轮才加的），配上实验室独立确认的业务恢复，

## 第六节：我自己拍的六个板

这六条你都可以推翻，推翻的话我改。

### ① 阅卷程序版本号 6.1 → 6.2，题库 3.2.1 → 3.2.2

判定规则整个换了，版本号必须跟着换——否则平台自带的防漂移机制会让新规则顶着旧名字混过去。
这是上一轮已经确立的规矩，我照办。冻结的评分依赖摘要也重新算了（新判据那份代码一起进摘要）。

**题面里症状那一段一个字都没动**（指纹和 3.2.0 / 3.2.1 完全相同），
多出来的只有一句「答卷要长什么样」。

### ② 「能动手的题由业务复测兜底」——手册里这条有两种读法，我选了一种

手册第 5.5 节那张表，能动手的题那一行写的是「**状态对** + 只改一处 + 业务从断到通」；
但第 3 节第②条和第 7 节块 2 写的是「**根因不再一票否决**，由业务复测**兜底**」。

这两句是冲突的。我按**「兜底」**理解：

> 能动手的题，**指认对了** 或者 **业务确实修好了**，这道门就过。两者取其一。

理由是第 4 节那条最硬的依据——今天那两次**诊断说法不合格但业务真的恢复了**，
你写在手册里的结论是「把编号这一关拿掉，这两次是满盘通过的」。
按「状态对」那种读法，它们仍然过不了。

**如果你的本意是"必须两条都满足"，说一声我改回去**，改动只有一行。

### ③ 建议质量那一项，不再复查一遍根因

「建议有没有挂在一个被接受的结论上」这一项，以前还要再判一次根因对不对。
根因已经有专门的一维在打分、在不能动手的题上还是硬门，再判一次就是同一件事判两遍，
而且会从侧门把"一票否决"放回来。现在它只判结构（建议有没有真的指向本次的领先假设）。

### ④ 新增第四个基线考生「贪心考生」

见第五节那张表。不加它的话，"门交给结果"这条新规矩没有任何东西钉着。

### ⑤ 大小写不参与比对

考生把规则表名写成小写，不算错。理由：**指的是同一行记录，
因为大小写扣分是拿排版当考点**——这正是这一轮要消灭的那类毛病。
除大小写之外，字眼和取值一律精确比对。

### ⑥ 「原本该在、现在不见了」那一类，考生要把那样东西的完整地址写出来

例如「某条路由被删了」。这一类没有记录可以指——东西已经没了。
所以考场不去翻记录，直接拿考生写的内容和真值比。代价是考生必须写全，
写一半（比如只说"少了一条静态路由"）就对不上。

> 这一类目前只有一个故障（N6 路由缺失），而且它本来就因为证据召回不够进不了考场。
