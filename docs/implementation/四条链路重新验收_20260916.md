## 2. 根因：Evidence Gate 的唯一升级手段是"停"

链路② 的 `public_events` 完整重建出了节点路径（事件 80–86）：

```
80 release_action_lease
81 investigation.reopened          ← 动作验证有效后，图确实回头了（不是"图回不去"）
82 resume_investigation
83 revise_hypotheses      qd=finalize                 ← 模型说：查完了，发布
84 quality_gate           qd=continue → adjudicate    ← 引擎推翻，强制复核一次
85 adjudicate_hypotheses  qd=finalize                 ← 模型又说：发布
86 quality_gate           qd=insufficient_evidence    ← 引擎再次推翻，判停
```

对应代码 `src/opsmind_langgraph/graph/builder.py:1197` `quality_gate` 的最后一个 `else`：

```python
else:
    digest = _hypothesis_digest(state)
    reviewed = set(state.get("adjudicated_hypothesis_digests", ()))
    if state.get("evidence") and digest not in reviewed:
        decision = QualityDecision.CONTINUE.value      # 复核一次（事件 84）
        gate_route = "adjudicate"
        gate_override_reason = "evidence_gate.relation_review_required"
    else:
        decision = QualityDecision.INSUFFICIENT_EVIDENCE.value   # 事件 86
        gate_override_reason = "evidence_gate.publication_blocked_after_review"
```

而 `INSUFFICIENT_EVIDENCE` 在 `builder.py:2359` 的路由表里**只有一个出口**：

```python
QualityDecision.FINALIZE: "finalize_and_learn",
QualityDecision.INSUFFICIENT_EVIDENCE: "finalize_and_learn",
```

**Gate 的判断本身没错**（`network.restore_policy` 对 n2 的动作顺带重启了无线运行时，
所以"业务恢复"不足以独证"只有 DROP 规则移除起效"——这是对的、也是诚实的）。
错的是 **Gate 能说"不行"、能说"再复核一遍"，但说不出"去补 X"**。

最刺眼的一点：判停的那一刻，引擎在同一个节点里算好并写进 state 的
`remaining_evidence_opportunities` 第一项就是 **`capture_protocol_summary`**——
正是 Gate 自己点名要的那份"动作后 SCTP 关联与 NGAP 原始帧"。
**LG 知道缺什么、手上有那把工具、图也支持回头，但四个枚举值里没有一个能表达"去补这个"。**

`unresolved_questions` 第一条是 LG 自己写的：
> 动作后未重新采集 SCTP 关联与 NGAP 原始帧，阻断将 h3 升级为 confirmed。

## 3. 这一段对迭代故事的意义

这不是"agent 比 workflow 聪明"，两边模型同源。差的是**词汇量**：

- **LG**：模型对路径的唯一发言权是 `AgentDecision.quality_decision`，4 个枚举值
  （continue / propose_action / finalize / insufficient_evidence）。Gate 与模型意见不一致时
  **Gate 赢**，而 Gate 赢的那个枚举值通向出口。模型两次说"发布"，两次被改判。
- **AH**：没有 Gate 节点、没有枚举、没有改判。模型读到同一个缺口，直接再调一次采集工具。
  同一道故障，AH 发布了 confidence 0.92 的根因、17 条聚焦证据、并逐条否证了竞争假设。

**"开放调查"的实质，在这一条 trace 里具象成了一件很小的事：能不能说出"我还想再看一眼"。**

⚠️ 同时要说清楚边界：这**不能**反过来证明 AH 更稳。两边各只有 2 个样本。
批量测不同类别故障的待办见 `待办_编排方式对比与批量故障评测_20260916.md`。
