连带删掉：

- `gradeTrial` 里的 `remediationObserved`（它只为文本判据的时序而存在）

**改法**：

| 原来 | 改成 |
|---|---|
| 没填事实编号 → 退回文本判据 | 没填 → **直接判否**（`gate_passed: false`，理由 `root_cause_facts_not_declared`） |

**`ground_truth.forbidden_claims` 怎么处理**：**字段保留，但任何判定代码都不许读它**。
它记录的是"这道题的经典错答"，是有价值的出题知识，第四批做词表扩充时要把它转成
事实编号（"不许把这几条事实提名成病根"）。
**加一条测试断言没有任何打分路径读它**，免得哪天悄悄复活。

**探针要跟着改**（它们大量依赖文本判据）：

- `probe5/6/7`、`grader-fact-discriminance.mjs`、`grader-live-mintability.mjs`、

而不是只为考试存在。运维打开报告直接看到：

**怎么做：从已有字段推导，不要让模型多写东西。** 推导规则：

```

已排除 = 被否决的假设 + 它们的反证证据编号
```

推导比新加字段好：不增加模型负担，也不可能和别处自相矛盾。
