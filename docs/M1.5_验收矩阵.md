## 三、自动验收证据

运行：

```text
npm run m15:verify
```

必须同时满足：

1. 内核、Agent 运行时和控制 API 测试全部通过；
2. Claude Agent SDK 适配检查通过；
3. 禁止图工作流检查通过；
4. 密钥扫描无发现；
5. 全新空库运行 12/12 条 L0 Trial；
6. 每条 Trial 恰有一个确定性 Code Grader Run；
7. Span 类型完整、脱敏生效、账本有效；
8. 篡改 Trace 与 Trial Result 被数据库拒绝；
9. 公开控制台检查与生产构建通过。

证据位置：

- `artifacts/m15/M1.5验收结论.json`
- `artifacts/m15/M1.5统计复算.json`
- `artifacts/m15/M1.5测量系统加固验收报告.md`
- `artifacts/m15/dataset-registry.public.json`
- `artifacts/m15/private-labels.sha256`

## 四、正式 Pilot 验收

使用 `config/m15-pilot.manifest.json` 前必须把提交号和镜像摘要占位符替换为冻结值。正式 Pilot 为 15 Case × 2 架构 × 3 次重复，共 90 Trial。

正式结果必须报告：

- 完成率、失败率、超时率和安全事件；
- 八维代码评分与不可补偿硬门禁；
- 同 Case 配对差值及按 Case 聚类的 95% Bootstrap 区间；
- pass@3 与 pass³；
- 代表成功、失败、Lucky Pass、工具恢复和未知停止轨迹；
- 仿真等级与不能外推到生产的限制；
- 同口径成本，若口径不一致则明确禁止比较。

## 五、可选专家盲审

专家资源可用时，可按需增强证据可信度，但不属于验收门禁：

1. 管理员显式选择代表性、争议或高风险 Trial，不自动全量建任务；
2. 两名具备对应 5G/运维资质的专家独立盲评，分歧可由第三名专家仲裁；
3. 所有决定具名、带证据引用、只追加写入账本；
4. 专家结论单独展示为质量信号，不改变 Code Grader 历史分数；
5. 缺少专家、样本不足或专家意见分歧，均不阻塞 M1.5、正式 Pilot 或合成基准排名。
