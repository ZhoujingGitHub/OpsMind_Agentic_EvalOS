# 真实考生接入边界与基础设施

这里存放的是 EvalOS 拥有的部署和网络接入包装，不包含任何考生推理、工具选择或故障处置逻辑。

- `agent-harness/`：把冻结的 Agent+Harness 源码构建成独立产品服务；不修改其源码。
- `relay-worker.py`：运行在产品服务器上的出站 HTTPS 中继。考生凭据始终留在产品服务器，EvalOS 只得到产品公开接口的请求结果。
- `opsmind-evalos-candidate-relay@.service`：中继的最小权限系统服务。

真实 Trial 只能调用两套产品已经公开的 API。中继在两端都使用固定接口白名单，并用每个考生独立的 Ed25519 身份签名。它不能访问任意网址、不能选择工具、不能替考，也不能修改评分。身份、版本摘要、运行证据和网络接入记录由 EvalOS 独立保全。
